FileLens is a powerful dual-pane file manager for Android with built-in security inspection. Browse, organize, and manage your files — then go deeper: inspect any file for hidden risks before you open or share it.

📂 FILE MANAGER
• Dual-pane Commander Mode on tablets and Samsung DeX. Single pane on phones.
• Copy, move, rename, delete with undo. Soft-delete to recoverable trash.
• Batch rename with patterns, find/replace, and regular expressions.
• Compare two files: text diff, JSON/XML structural diff, image side-by-side.
• Compare and sync two folders. Find duplicates by SHA-256.
• Full keyboard support with customizable Norton Commander F-key shortcuts.
• Verify downloads against a pasted SHA-256 or MD5 hash.

🔍 SECURITY INSPECTOR
• Magic-bytes detection catches extension mismatches — that .jpg might be an executable.
• Risk badges flag GPS data in photos, JavaScript in PDFs, macros in Office files, active content in archives.
• Local trust score shows the top reasons a file might be risky.
• APK inspector: permissions, signatures, debug flags, trackers, native libraries.

📄 DEEP FILE PREVIEW
• Images: EXIF data including GPS, camera model, dates.
• Documents: DOCX, XLSX, PPTX with revision history, hidden sheets, external links.
• PDFs: page thumbnails, JavaScript detection, embedded files, encryption status.
• Archives: browse ZIP, JAR, APK, TAR, EPUB contents without extracting.
• Audio/Video: tags, codec, duration, album art, video thumbnails.
• Code & Config: syntax-highlighted preview with secrets scan for JSON, XML, YAML, .env files.
• SQLite: schema browser, table viewer, read-only query tool.
• Binary: hex viewer, entropy analysis, file header detection.

🔒 PRIVACY PROTECTION
• Strip EXIF, OOXML, and PDF metadata before sharing — no location leaks.
• Share cleaned copies with one tap.
• Batch privacy audit: scan entire folders and export cleaned copies as ZIP.
• Generate inspection reports in Markdown or JSON.

🛡️ OFFLINE & PRIVATE
• No accounts required. No analytics beyond crash reporting.
• No network calls during normal use — everything runs on your device.
• Settings and bookmarks backed up to a local JSON file you control.

Perfect for security-conscious users, journalists, sysadmins, developers, and anyone who wants to understand what's inside their files before sharing them.
