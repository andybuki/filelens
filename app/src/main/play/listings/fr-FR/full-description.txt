FileLens est un puissant gestionnaire de fichiers à double panneau pour Android avec inspection de sécurité intégrée. Parcourez, organisez et gérez vos fichiers — puis allez plus loin : inspectez n'importe quel fichier à la recherche de risques cachés avant de l'ouvrir ou de le partager.

📂 GESTIONNAIRE DE FICHIERS
• Mode Commander à double panneau sur tablettes et Samsung DeX. Panneau unique sur téléphone.
• Copier, déplacer, renommer, supprimer avec annulation. Suppression douce vers une corbeille récupérable.
• Renommage par lot avec modèles, rechercher/remplacer et expressions régulières.
• Comparer deux fichiers : diff textuel, diff structurel JSON/XML, images côte à côte.
• Comparer et synchroniser deux dossiers. Trouver les doublons par SHA-256.
• Support clavier complet avec raccourcis F-touches Norton Commander personnalisables.
• Vérifier les téléchargements avec un hash SHA-256 ou MD5.

🔍 INSPECTEUR DE SÉCURITÉ
• La détection magic-bytes repère les incohérences d'extension — ce .jpg pourrait être un exécutable.
• Les badges de risque signalent les données GPS dans les photos, le JavaScript dans les PDF, les macros dans les fichiers Office, le contenu actif dans les archives.
• Score de confiance local montrant les principales raisons pour lesquelles un fichier pourrait être risqué.
• Inspecteur APK : permissions, signatures, drapeaux de débogage, trackers, bibliothèques natives.

📄 APERÇU APPROFONDI DES FICHIERS
• Images : données EXIF incluant GPS, modèle d'appareil photo, dates.
• Documents : DOCX, XLSX, PPTX avec historique des révisions, feuilles masquées, liens externes.
• PDF : miniatures de pages, détection JavaScript, fichiers intégrés, état du chiffrement.
• Archives : parcourir le contenu ZIP, JAR, APK, TAR, EPUB sans extraction.
• Audio/Vidéo : tags, codec, durée, pochette d'album, miniatures vidéo.
• Code & Config : aperçu avec coloration syntaxique et scan de secrets pour JSON, XML, YAML, .env.
• SQLite : navigateur de schéma, visualiseur de tables, outil de requête en lecture seule.
• Binaire : visualiseur hexadécimal, analyse d'entropie, détection d'en-tête de fichier.

🔒 PROTECTION DE LA VIE PRIVÉE
• Supprimer les métadonnées EXIF, OOXML et PDF avant le partage — aucune fuite de localisation.
• Partager des copies nettoyées en un tap.
• Audit de confidentialité par lot : scanner des dossiers entiers et exporter les copies nettoyées en ZIP.
• Générer des rapports d'inspection en Markdown ou JSON.

🛡️ HORS LIGNE & PRIVÉ
• Aucun compte requis. Aucune analyse au-delà des rapports de plantage.
• Aucun appel réseau en utilisation normale — tout fonctionne sur votre appareil.
• Paramètres et favoris sauvegardés dans un fichier JSON local que vous contrôlez.
