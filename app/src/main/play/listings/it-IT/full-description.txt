FileLens è un potente gestore di file a doppio pannello per Android con ispezione di sicurezza integrata. Sfoglia, organizza e gestisci i tuoi file — poi vai più a fondo: ispeziona qualsiasi file alla ricerca di rischi nascosti prima di aprirlo o condividerlo.

📂 GESTORE FILE
• Modalità Commander a doppio pannello su tablet e Samsung DeX. Pannello singolo su telefono.
• Copia, sposta, rinomina, elimina con annullamento. Eliminazione soft in cestino recuperabile.
• Rinomina in batch con pattern, cerca/sostituisci ed espressioni regolari.
• Confronta due file: diff testuale, diff strutturale JSON/XML, immagini affiancate.
• Confronta e sincronizza due cartelle. Trova duplicati tramite SHA-256.
• Supporto tastiera completo con scorciatoie F personalizzabili stile Norton Commander.
• Verifica i download con hash SHA-256 o MD5.

🔍 ISPETTORE DI SICUREZZA
• Il rilevamento magic-bytes cattura le discrepanze di estensione — quel .jpg potrebbe essere un eseguibile.
• I badge di rischio segnalano dati GPS nelle foto, JavaScript nei PDF, macro nei file Office, contenuti attivi negli archivi.
• Punteggio di fiducia locale che mostra i principali motivi per cui un file potrebbe essere rischioso.
• Ispettore APK: permessi, firme, flag di debug, tracker, librerie native.

📄 ANTEPRIMA APPROFONDITA DEI FILE
• Immagini: dati EXIF inclusi GPS, modello fotocamera, date.
• Documenti: DOCX, XLSX, PPTX con cronologia revisioni, fogli nascosti, link esterni.
• PDF: miniature pagine, rilevamento JavaScript, file incorporati, stato crittografia.
• Archivi: sfoglia contenuti ZIP, JAR, APK, TAR, EPUB senza estrarre.
• Audio/Video: tag, codec, durata, copertina album, miniature video.
• Codice e Config: anteprima con evidenziazione sintassi e scansione segreti per JSON, XML, YAML, .env.
• SQLite: browser schema, visualizzatore tabelle, strumento query in sola lettura.
• Binario: visualizzatore hex, analisi entropia, rilevamento header file.

🔒 PROTEZIONE DELLA PRIVACY
• Rimuovi metadati EXIF, OOXML e PDF prima della condivisione — nessuna fuga di posizione.
• Condividi copie pulite con un tap.
• Audit privacy in batch: scansiona intere cartelle ed esporta copie pulite come ZIP.
• Genera report di ispezione in Markdown o JSON.

🛡️ OFFLINE E PRIVATO
• Nessun account richiesto. Nessuna analisi oltre ai report di crash di base.
• Nessuna chiamata di rete durante l'uso normale — tutto funziona sul tuo dispositivo.
• Impostazioni e segnalibri salvati in un file JSON locale che controlli tu.
