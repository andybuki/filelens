FileLens는 보안 검사 기능이 내장된 강력한 듀얼 패널 Android 파일 관리자입니다. 파일을 탐색하고 정리하고 관리한 다음, 더 깊이 들여다보세요: 파일을 열거나 공유하기 전에 숨겨진 위험을 검사할 수 있습니다.

📂 파일 관리자
• 태블릿과 Samsung DeX에서 듀얼 패널 Commander 모드. 휴대폰에서는 싱글 패널.
• 복사, 이동, 이름 변경, 삭제(실행 취소 지원). 복구 가능한 휴지통으로 소프트 삭제.
• 패턴, 찾기/바꾸기, 정규식을 사용한 일괄 이름 변경.
• 두 파일 비교: 텍스트 diff, JSON/XML 구조 diff, 이미지 나란히 비교.
• 두 폴더 비교 및 동기화. SHA-256으로 중복 파일 찾기.
• 사용자 정의 가능한 Norton Commander F키 단축키로 풀 키보드 지원.
• SHA-256 또는 MD5 해시로 다운로드 검증.

🔍 보안 검사기
• 매직바이트 감지로 확장자 불일치 포착 — 그 .jpg는 실행 파일일 수 있습니다.
• 위험 배지가 사진의 GPS 데이터, PDF의 JavaScript, Office 파일의 매크로, 아카이브의 활성 콘텐츠를 경고.
• 로컬 신뢰 점수가 파일이 위험할 수 있는 주요 이유를 표시.
• APK 검사기: 권한, 서명, 디버그 플래그, 트래커, 네이티브 라이브러리.

📄 심층 파일 미리보기
• 이미지: GPS, 카메라 모델, 날짜를 포함한 EXIF 데이터.
• 문서: DOCX, XLSX, PPTX 수정 이력, 숨겨진 시트, 외부 링크.
• PDF: 페이지 썸네일, JavaScript 감지, 임베디드 파일, 암호화 상태.
• 아카이브: ZIP, JAR, APK, TAR, EPUB 내용을 압축 해제 없이 탐색.
• 오디오/비디오: 태그, 코덱, 재생 시간, 앨범 아트, 비디오 썸네일.
• 코드 및 설정: JSON, XML, YAML, .env 파일의 비밀 스캔이 포함된 구문 강조 미리보기.
• SQLite: 스키마 브라우저, 테이블 뷰어, 읽기 전용 쿼리 도구.
• 바이너리: hex 뷰어, 엔트로피 분석, 파일 헤더 감지.

🔒 개인정보 보호
• 공유 전 EXIF, OOXML, PDF 메타데이터 제거 — 위치 유출 없음.
• 한 번의 탭으로 정리된 사본 공유.
• 일괄 개인정보 감사: 전체 폴더 스캔 및 정리된 사본을 ZIP으로 내보내기.
• Markdown 또는 JSON 형식으로 검사 보고서 생성.

🛡️ 오프라인 & 프라이빗
• 계정 불필요. 기본 충돌 보고 외 분석 없음.
• 일반 사용 시 네트워크 호출 없음 — 모든 것이 기기에서 실행.
• 설정과 북마크는 사용자가 관리하는 로컬 JSON 파일에 백업.

보안에 민감한 사용자, 기자, 시스템 관리자, 개발자, 그리고 파일을 공유하기 전에 그 안에 무엇이 있는지 알고 싶은 모든 분에게 적합합니다.
