FileLens 是一款功能强大的双面板 Android 文件管理器，内置安全检查功能。浏览、整理和管理您的文件——然后深入了解：在打开或分享之前检查任何文件是否存在隐藏风险。

📂 文件管理器
• 平板电脑和 Samsung DeX 上的双面板 Commander 模式。手机上为单面板。
• 复制、移动、重命名、删除并支持撤销。软删除到可恢复的回收站。
• 批量重命名，支持模式匹配、查找/替换和正则表达式。
• 比较两个文件：文本差异、JSON/XML 结构差异、图片并排对比。
• 比较和同步两个文件夹。通过 SHA-256 查找重复文件。
• 完整键盘支持，可自定义 Norton Commander 风格的 F 键快捷方式。
• 使用 SHA-256 或 MD5 哈希验证下载文件。

🔍 安全检查器
• Magic-bytes 检测捕获扩展名不匹配——那个 .jpg 可能实际上是可执行文件。
• 风险标志警告照片中的 GPS 数据、PDF 中的 JavaScript、Office 文件中的宏、压缩包中的活动内容。
• 本地信任评分显示文件可能存在风险的主要原因。
• APK 检查器：权限、签名、调试标志、追踪器、原生库。

📄 深度文件预览
• 图片：EXIF 数据，包括 GPS、相机型号、日期。
• 文档：DOCX、XLSX、PPTX，含修订历史、隐藏工作表、外部链接。
• PDF：页面缩略图、JavaScript 检测、嵌入文件、加密状态。
• 压缩包：浏览 ZIP、JAR、APK、TAR、EPUB 内容无需解压。
• 音频/视频：标签、编解码器、时长、专辑封面、视频缩略图。
• 代码与配置：语法高亮预览，支持 JSON、XML、YAML、.env 文件的密钥扫描。
• SQLite：架构浏览器、表格查看器、只读查询工具。
• 二进制：十六进制查看器、熵分析、文件头检测。

🔒 隐私保护
• 分享前去除 EXIF、OOXML 和 PDF 元数据——防止位置泄露。
• 一键分享清理后的副本。
• 批量隐私审计：扫描整个文件夹并将清理后的副本导出为 ZIP。
• 生成 Markdown 或 JSON 格式的检查报告。

🛡️ 离线且私密
• 无需账户。除基本崩溃报告外无任何分析。
• 正常使用时无网络连接——一切在您的设备上运行。
• 设置和书签备份到您控制的本地 JSON 文件。

非常适合注重安全的用户、记者、系统管理员、开发人员以及所有想在分享文件前了解其真实内容的人。
