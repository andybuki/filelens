FileLens は、ファイルを開いたり共有したりする前に、その中身を理解できる Android 向けのスマートなファイルマネージャーです。

INSPECT BEFORE YOU OPEN（開く前に確認）
• マジックバイト検出により拡張子の偽装を検出します（その .jpg は実は実行ファイルかもしれません）。
• 一般的なすべてのファイル形式に対して、プレビュー・メタデータ・構造タブを横並びで表示。
• リスクバッジが写真の GPS、PDF の JavaScript、DOCX の変更履歴、Excel の非表示シート、アーカイブ内のアクティブコンテンツなどを指摘します。
• ローカルの信頼スコアと、それに影響した主な理由を表示。

DEEP COVERAGE（幅広い対応）
• 画像：GPS、カメラ、日付を含む EXIF、オプションでクリーニング。
• ドキュメント：DOCX、XLSX、PPTX の改訂、非表示シート、マクロ、外部リンク。
• PDF：サムネイル、JavaScript、埋め込みファイル、暗号化ステータス。
• アーカイブ：ZIP、JAR、APK、OOXML、TAR、TAR.GZ、EPUB。展開せずに内容を閲覧。
• APK：権限、署名、デバッグ／バックアップフラグ、ネイティブライブラリ、トラッカー。
• 音声／動画：タグ、再生時間、コーデック、アルバムアート、動画サムネイル。
• コード／テキスト／設定：シンタックスハイライト付きプレビュー、JSON、XML、YAML、TOML、INI、.env、ログ全体のシークレットスキャン。
• SQLite：スキーマ、テーブル行、読み取り専用のクエリブラウザ。
• バイナリ：hex ビュー、エントロピー、ELF／DEX／SQLite ヘッダー。

COMMANDER MODE（コマンダーモード）
• スマホでは単一パネル、タブレットや DeX ではデュアルファイルパネル。
• フルキーボード対応の Norton-style F キーショートカット。すべてのバインドはカスタマイズ可能。
• コピー、移動、リネーム、パターンによる一括リネーム（{n}、{name}、{ext}、検索／置換、regex）。
• 復元可能な .trash ディレクトリへのソフト削除と、Ctrl+Z による取り消し。
• 2 ファイルの比較（テキスト diff、JSON／XML 構造 diff、画像の並列表示、チェックサム）。
• 2 フォルダの比較（左のみ、右のみ、変更あり、同内容で名前違い）と同期アクション。
• SHA-256 で重複を検出し、ワンタップで「古い余分を削除」。
• 貼り付けたハッシュ（SHA-256 または MD5）でダウンロードを検証。

PRIVACY-FIRST（プライバシー優先）
• 「クリーン化したコピーを共有」フロー用に EXIF、OOXML、PDF メタデータを除去。
• フォルダの一括プライバシー監査、クリーン化したコピーを共有可能な ZIP にパック。
• 検査レポートを Markdown または JSON として生成。

OFFLINE, ON-DEVICE（オフライン・端末内処理）
• アカウント不要、基本的なクラッシュレポート以外の解析なし、通常動作中のネットワーク通信なし。
• 設定、ブックマーク、最近のファイル、よく使うフォルダは、あなたが管理する JSON ファイルにバックアップされます。

いじるのが好きな人、セキュリティ意識の高いユーザー、ジャーナリスト、システム管理者、そしてスマホ上のファイルを共有する前に中身を本当に知りたいすべての人のために設計されました。
