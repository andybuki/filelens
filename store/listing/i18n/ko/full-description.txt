FileLens는 파일을 열거나 공유하기 전에 그 안에 무엇이 있는지 파악할 수 있게 해주는 스마트한 안드로이드 파일 관리자입니다.

■ 열기 전에 분석하세요
• 매직 바이트 감지로 확장자 불일치를 잡아냅니다(그 .jpg가 실제로는 실행 파일일 수 있습니다).
• 모든 일반 파일 형식에 대해 미리보기, 메타데이터, 구조 탭을 나란히 제공합니다.
• 위험 배지가 사진의 GPS, PDF의 JavaScript, DOCX의 변경 추적, 숨겨진 Excel 시트, 아카이브의 활성 콘텐츠 등을 표시합니다.
• 로컬 신뢰 점수와 그에 영향을 준 주요 이유를 함께 제공합니다.

■ 폭넓은 지원
• 이미지: GPS, 카메라, 날짜를 포함한 EXIF 및 선택적 정리.
• 문서: DOCX, XLSX, PPTX 수정 이력, 숨겨진 시트, 매크로, 외부 링크.
• PDF: 썸네일, JavaScript, 임베디드 파일, 암호화 상태.
• 아카이브: ZIP, JAR, APK, OOXML, TAR, TAR.GZ, EPUB. 압축 풀지 않고 내용 탐색.
• APK: 권한, 서명, 디버그/백업 플래그, 네이티브 라이브러리, 트래커.
• 오디오/비디오: 태그, 길이, 코덱, 앨범 아트, 비디오 썸네일.
• 코드/텍스트/설정: 구문 강조 미리보기, JSON, XML, YAML, TOML, INI, .env, 로그 전반의 시크릿 스캔.
• SQLite: 스키마, 테이블 행, 읽기 전용 쿼리 브라우저.
• 바이너리: 헥스 뷰, 엔트로피, ELF/DEX/SQLite 헤더.

■ 커맨더 모드
• 휴대폰에서는 단일 패널, 태블릿과 DeX에서는 듀얼 파일 패널.
• Norton 스타일 풀 키보드 F키 단축키. 모든 바인딩 사용자 지정 가능.
• 복사, 이동, 이름 변경, 패턴 기반 일괄 이름 변경({n}, {name}, {ext}, 찾기/바꾸기, 정규식).
• 복구 가능한 .trash 디렉터리로 소프트 삭제, Ctrl+Z 실행 취소.
• 두 파일 비교(텍스트 diff, JSON/XML 구조 diff, 이미지 나란히, 체크섬).
• 두 폴더 비교(왼쪽 전용, 오른쪽 전용, 변경됨, 같은 내용 다른 이름)와 동기화 작업.
• SHA-256으로 중복 찾기, 원탭으로 "오래된 사본 삭제".
• 붙여넣은 해시(SHA-256 또는 MD5)로 다운로드 검증.

■ 프라이버시 우선
• "정리된 사본 공유" 흐름을 위해 EXIF, OOXML, PDF 메타데이터 제거.
• 폴더 단위 일괄 프라이버시 감사, 정리된 사본을 공유 가능한 ZIP으로 패키징.
• 검사 보고서를 Markdown 또는 JSON으로 생성.

■ 오프라인, 온디바이스
• 계정 없음, 기본 크래시 보고 외 분석 없음, 일반 작동 중 네트워크 호출 없음.
• 설정, 북마크, 최근 파일, 자주 사용하는 폴더를 사용자가 제어하는 JSON 파일로 백업.

기기 안의 파일을 공유하기 전에 실제로 무엇이 들어 있는지 알고 싶은 만지작거리기 좋아하는 사용자, 보안 의식이 있는 사용자, 언론인, 시스템 관리자 그리고 모든 분을 위해 설계되었습니다.
