FileLens — умный файловый менеджер для Android, который помогает понять, что находится в файле, до того как вы его откроете или отправите.

ПРОВЕРЯЙТЕ ДО ОТКРЫТИЯ
• Определение по магическим байтам ловит несоответствия расширения (этот .jpg может оказаться исполняемым файлом).
• Параллельные вкладки превью, метаданных и структуры для каждого распространённого типа файлов.
• Метки риска указывают на GPS в фото, JavaScript в PDF, отслеживаемые правки в DOCX, скрытые листы Excel, активное содержимое в архивах.
• Локальная оценка доверия с главными факторами, повлиявшими на неё.

ГЛУБОКОЕ ПОКРЫТИЕ
• Изображения: EXIF, включая GPS, камеру, даты, с опциональной очисткой.
• Документы: правки DOCX, XLSX, PPTX, скрытые листы, макросы, внешние ссылки.
• PDF: миниатюры, JavaScript, встроенные файлы, статус шифрования.
• Архивы: ZIP, JAR, APK, OOXML, TAR, TAR.GZ, EPUB. Просмотр содержимого без распаковки.
• APK: разрешения, подписи, флаги отладки/бэкапа, нативные библиотеки, трекеры.
• Аудио/видео: теги, длительность, кодек, обложки, превью видео.
• Код/текст/конфиги: подсветка синтаксиса, поиск секретов в JSON, XML, YAML, TOML, INI, .env, логах.
• SQLite: схема, строки таблиц, браузер запросов в режиме чтения.
• Бинарные файлы: hex-просмотр, энтропия, заголовки ELF/DEX/SQLite.

РЕЖИМ КОМАНДИРА
• Одна панель на телефоне, две панели файлов на планшетах и DeX.
• Norton-style F-клавиши с полной поддержкой клавиатуры. Все привязки настраиваются.
• Копирование, перемещение, переименование, пакетное переименование по шаблонам ({n}, {name}, {ext}, поиск/замена, regex).
• Мягкое удаление в восстанавливаемую папку .trash с отменой через Ctrl+Z.
• Сравнение двух файлов (текстовый diff, структурный diff JSON/XML, изображения бок о бок, контрольные суммы).
• Сравнение двух папок (только слева, только справа, изменённые, одинаковое содержимое — разные имена) с действиями синхронизации.
• Поиск дубликатов по SHA-256 с удалением старых копий в одно касание.
• Проверка загрузки по вставленному хешу (SHA-256 или MD5).

КОНФИДЕНЦИАЛЬНОСТЬ ПРЕВЫШЕ ВСЕГО
• Удаляет EXIF, OOXML, метаданные PDF для отправки очищенной копии.
• Пакетный аудит приватности папки; упаковка очищенных копий в ZIP для отправки.
• Отчёты об инспекции в формате Markdown или JSON.

ОФЛАЙН, НА УСТРОЙСТВЕ
• Без аккаунтов, без аналитики кроме базовых отчётов о сбоях, без сетевых вызовов при обычной работе.
• Настройки, закладки, недавние файлы и частые папки бэкапятся в JSON-файл, которым управляете вы.

Создано для энтузиастов, пользователей, заботящихся о безопасности, журналистов, системных администраторов и всех, кто хочет знать, что на самом деле внутри файлов на их телефоне, прежде чем поделиться ими.
